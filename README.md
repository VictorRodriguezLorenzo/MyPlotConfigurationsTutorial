# TTDMsimp dileptonic analysis tutorial

This directory is prepared as a step-by-step tutorial with all the basics to run
an analysis with mkShapesRDF. More documentation can be found at:

- [mkShapesRDF tutorial slides](https://docs.google.com/presentation/d/1UlJUYIIA2-Kbpj_wDD4EKDMNEH01GeI-9GDHDYxhfpI/edit?slide=id.g2df8cadc7b0_0_269#slide=id.g2df8cadc7b0_0_269)
- [PlotsConfigurationsRun3 repository](https://github.com/latinos/PlotsConfigurationsRun3)

Three independent self-working setups are provided .

1. `01_basic_cuts`: based on the NPS-26-025 2022 analysis configuration, but 
    reducing it to the simplest self-working configuration
2. `02_extended`: a self-contained 2022 setup adding new calculations,
   macros, and DNN training/evaluation files.
3. `03_complete`: the whole dileptonic setup, including all available years/campaigns,
   Run 3 merging, datacards, and limits.

Every setup has its own README and its own copies of the files it needs.
